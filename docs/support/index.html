Syncline support

How can we help?

For app problems, include your Apple platform, OS version, Syncline version, and the Docmost server version when possible. Never include passwords or session cookies.

Contact

Email patryk@chef.ski for private support questions, or open a GitHub issue for reproducible bugs and feature requests.

Before reporting a connection problem

  • Confirm the workspace opens in a web browser using the same HTTPS address.
  • Check that your email and password work on the Docmost web app.
  • Ask your administrator whether the workspace requires an authentication method not yet supported by Syncline.
  • Try signing out and selecting the workspace again.

Independent project

Syncline is an independent open-source client and is not affiliated with Docmost. Questions about server hosting, billing, or the Docmost web product should be directed to your server administrator or Docmost.
